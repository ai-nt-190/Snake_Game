# 🐍 Snake Game

A basic 90s-style Snake Game built using Python and the Turtle graphics module.

## 🎮 Features

- Classic retro Snake gameplay
- Simple graphics using Python's Turtle module
- Keyboard controls for snake movement
- Score tracking

## 🛠️ Technologies Used

- Python
- Turtle Graphics Module

## 🚀 How to Run

Run the game using:

```bash
python main.py
```

## 🕹️ How to Play

- Use the arrow keys to control the snake.
- Eat the food to grow longer and increase your score.
- Avoid hitting the walls or your own body.
- Try to achieve the highest score possible!

- Handling keyboard events
- Implementing basic game logic
